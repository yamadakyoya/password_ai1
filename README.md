# Password AI

パスワードのサンプルを作ってAIに学習させ、入力したパスワードのランクを判定するPython製のデスクトップアプリです。学習済みモデルを使って、20～24文字のパスワードも生成できます。

## 使用技術

- Python
- pandas
- scikit-learn
- Matplotlib
- Tkinter
- CSV
- joblib

## 1. データセットの作成 generate_passwords.py

PythonでA・B・Cの各ランク2,000件、合計6,000件のデータを作り、CSVに保存します。パスワード本体と、AIの学習に使う特徴を記録します。
password_dataset.csvに保存されます。

| CSV項目 | 内容 |
|---|---|
| `password_id` | データを識別するID |
| `password` | パスワード本体 |
| `length` | 文字数 |
| `has_sequence` | 3文字以上の連番があるか |
| `has_repeated_pair` | 同じ文字が2回以上続くか |
| `has_weak_pattern` | 単語、キーボード配列、年、日付などがあるか |
| `rank` | A・B・Cの正解ランク |
| `pattern_type` | データの作り方 |

### 絶対条件

生成するパスワードは、次の条件を満たします。

- 7文字以上
- 小文字・大文字・数字・記号をそれぞれ含む
- 同じ文字が3回以上続かない

### 評価条件

次の特徴を調べ、CSVには「ある=1、ない=0」で記録します。

- 英字または数字の3文字以上の連番（逆向きも対象）
- 同じ文字が2回以上続く並び
- `password`、`hello`、キーボードの並び、1900～2026年の年、実在する月日

3回連続する同じ数字を避ける絶対条件があるため、たとえば1999年や2000年は年データとして生成しません。日付も実在する月日から、同じ文字が3回続かないものを使います。

### ランク設定

以下は、このプロジェクトでデータを作るために決めた独自ルールです。

| ランク | 基本ルール |
|---|---|
| C | 7～9文字。弱いパターンがある場合も基本的にC |
| B | 10～15文字、または弱いパターンのない20～24文字 |
| A | 基本的に16～19文字 |

16文字は連番があるとB、17～19文字は連番と同じ文字の連続の両方があるとBです。また、B用に作る16文字以上の年・日付データはBにします。

各ランクのデータには、ランダム、連番、同じ文字の繰り返し、連番と同じ文字の組み合わせ、年、日付などを含めています。Cには`password`などの単語やキーボード配列も含めています。

## 2. 予測モデルの作成 train_password_ai.py

password_dataset.csvを読み込み、各ランクのデータを学習用と問題用に分けます。

| ランク | 学習用 | 問題用 |
|---|---:|---:|
| A | 1,800件 | 200件 |
| B | 1,800件 | 200件 |
| C | 1,800件 | 200件 |
| 合計 | 5,400件 | 600件 |

Aの問題用データはランダムから選びます。B・Cは、連番：同じ文字の繰り返し：連番と同じ文字の組み合わせ：ランダムを**1：1：1：7**で選びます。各ランクで20件、20件、20件、140件です。年と日付のデータは問題用には選ばず、すべて学習用に使います。

ランダムフォレストを使い、次の4項目からランクを学習します。

- 文字数
- 連番の有無
- 同じ文字が続くか
- 弱いパターンがあるか

学習済みモデル(password_strength_model.joblib)を保存します。正答率は問題用データで確認し、表とランクごとの棒グラフを作ります。

## 3. デスクトップアプリ desktop_app.py

アプリは保存済みの予測モデル(password_strength_model.joblib)を直接読み込んで使います。アプリ内でCSVの読み込みや再学習はしません。

- 入力したパスワードのA・B・Cランクを表示
- 目のボタンでパスワードの表示・非表示を切り替え
- 20～24文字のパスワードを生成
- 判定前に、半角・7文字以上・小文字・大文字・数字・記号を含む・同じ文字を3回以上続けない、という絶対条件を確認
- 絶対条件を満たさない入力は判定せず、足りない条件を表示

判定時は、入力内容から学習時と同じ4つの特徴を作り、予測モデルに渡します。弱いパターンなどを調べる処理は、AIに渡す特徴を用意するために必要です。

## 4. 実行の流れ

CSVファイルを用意する  
↓  
学習用と問題用に分ける  
↓  
ランダムフォレストに学習させる  
↓  
学習済みモデルを保存する  
↓  
問題用データで正答率を確認する  
↓  
アプリでパスワードを判定・生成する
